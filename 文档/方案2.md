## 先明确核心问题

你要解决的本质是：**从海量噪音中，实时识别「正在发生的热点」**

加密领域的热点有几个特征：
- **时效性极强**（几小时内从冷到热）
- **多源共振**（Twitter + Discord + 广场同时出现同一话题）
- **信号密度**（单位时间内提及量激增）

## 第一层：统计过滤（不用LLM）

这一步目标是**把数据量砍掉90%**，纯规则，极快。

**具体做法：**

```python
# 1. Token频率统计（滑动时间窗口）
# 统计过去1小时 vs 过去24小时，某个词的出现频率比值
# 比值 > 3x → 可能是热点信号

# 2. 关键过滤规则
- 去掉转发/引用重复内容
- 去掉广告账号（低粉丝、高发帖频率）
- 保留：互动量前20%的帖子
- 保留：包含$代币名、项目名的内容

# 3. 聚类去重
# 用简单的TF-IDF或MinHash，把说同一件事的帖子合并成一条
```

处理后，你的数据量应该能从比如1万条 → 500-1000条。

## 关键设计：「热度激增检测」

这是整个系统最有价值的部分，纯统计实现：

```python
import time
from collections import defaultdict, deque

class HotTopicDetector:
    def __init__(self, window_short=3600, window_long=86400):
        self.short = defaultdict(deque)  # 1小时窗口
        self.long = defaultdict(deque)   # 24小时窗口
    
    def add(self, token, timestamp):
        self.short[token].append(timestamp)
        self.long[token].append(timestamp)
        # 清理过期数据...
    
    def get_surge_score(self, token, now):
        short_count = len(self.short[token])
        long_avg = len(self.long[token]) / 24  # 每小时平均
        if long_avg == 0:
            return 0
        return short_count / long_avg  # 激增倍数
```

激增倍数 > 5x 的词 → 直接触发第二层分析，不等定时任务。
